# V3.1 脉冲波 PolyBLEP 实验

- 日期：2026-11-21
- 状态：源码候选已实现；未发布，V3.1 正式目录保持不变。

## 修改

在当前 `src/audio_win32.c` 的方波路径加入两边沿 PolyBLEP 修正。每个采样点仍按相位比较生成脉冲；相位跨过上升沿和占空比对应的下降沿时，各加/减一个局部 BLEP 曲线。修正宽度为一个采样相位步长 `frequency / AUDIO_SAMPLE_RATE`。三角波、噪声、APU 寄存器逻辑、混音器和 WinMM 输出格式没有改动。

## PCM 对照

用相同 GCC `-O2` 构建 `scripts/audio-waveform-test.c`，基线音频实现取自 `dist/V3.1/final/source/audio_win32.c`，候选实现取自 `src/audio_win32.c`。探针先预热 0.1 秒，再生成 48 kHz、16 位 PCM 的 440 Hz、50% 占空比脉冲；以 Goertzel 计算整数谐波频点功率，并用基波功率归一化。

| 频带 | V3.1 基线 | PolyBLEP | 变化 |
|---|---:|---:|---:|
| 3–23 kHz 高次谐波 / 基波 | 0.07338598 | 0.06292848 | -14.2% |
| 10–23 kHz 高次谐波 / 基波 | 0.01349006 | 0.00721416 | -46.5% |

已有音频波形检查（基频过零、占空比、噪声模式、混音截幅和频率切换连续性）也通过。统计只覆盖合成音调，不等同于《魂斗罗》实际音频的受控听测。

- PCM 波形探针：通过；候选的 10–23 kHz 高频谐波比例低于 0.01。
- x86/x64 LLD 整体链接：通过。
- x86 Crinkler 链接：通过。
- 未启动 GUI、未播放或录制实际 ROM 音频；这符合本机仅使用后台 headless 验证的要求。
- 正式 `dist/V3.1/final/` 与 GitHub Release `v3.1` 均未修改。当前源码候选在 `src/audio_win32.c`，实验指标检查在 `scripts/audio-waveform-test.c`。
