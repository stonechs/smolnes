# smolnes V1.3 使用说明

## 启动和加载 ROM

V1.3 通过 Windows 原生“打开文件”窗口选择 ROM。它不再从命令行参数读取 ROM 路径，因此请按下面方式运行：

1. 按 Windows 版本选择一个 EXE。一般 64 位 Windows 用 x64；32 位 Windows 用 x86。压缩版占用磁盘更小，未压缩版更方便排查启动或杀毒软件误报。
2. 双击 EXE。
3. 在弹出的文件选择框中找到并选中 `.nes` 文件，再点“打开”。文件框默认筛选 `*.nes`，也可以切换到“所有文件”。
4. ROM 加载后会打开模拟器窗口。要换游戏，关闭模拟器，再重新启动并选择另一个 ROM。

取消文件选择框会直接退出程序。不要通过创建快捷方式并在“目标”后附加 ROM 路径来加载游戏；当前 V1.3 不支持这种方式。

## 四个发布文件

| 文件 | 适用系统 | 文件大小 | 说明 |
| --- | --- | ---: | --- |
| `smolnes-v1.3-native-caption-x64.exe` | 64 位 Windows | 10,240 B | 未压缩 x64 版 |
| `smolnes-v1.3-native-caption-x64-upx.exe` | 64 位 Windows | 8,192 B | UPX 压缩 x64 版 |
| `smolnes-v1.3-native-caption-x86.exe` | 32 位或 64 位 Windows | 9,728 B | 未压缩 x86 版 |
| `smolnes-v1.3-native-caption-x86-upack.exe` | 32 位或 64 位 Windows | 6,204 B | UPack 压缩 x86 版 |

四个文件使用相同的模拟器源码和 ROM 文件选择流程。x86 压缩版及 x64 压缩版只是对应未压缩程序的打包副本。

## ROM 兼容范围

ROM 文件需要包含有效的 iNES 头，并且必须使用模拟器已实现的功能/Mapper。体积优化版不代表完整 FC/NES 游戏兼容性；不同游戏的兼容程度可能不同。
